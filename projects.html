MemoryKit - Persistent Memory for AI Coding Assistants

Solo project
GitHub npm
Started November 2025 v2.0.0 published September 2026 ~73 weekly npm downloads · MIT license

The Problem (My Own):

My AI coding assistant forgot everything between sessions. Every new conversation, it re-read the same files and asked the same questions about my codebase, and I paid for those tokens every time.

What I Built:

An MCP server that gives Claude Code, Claude Desktop, GitHub Copilot, and Cursor memory that lasts across sessions. Memories are plain Markdown files stored locally and kept separate per project. No database, Docker, or API keys needed.

  • Four memory layers with different lifetimes: working (session context, expires after 7 days), facts and procedures (permanent), and episodes (bugs and incidents, compacted after 30 days)
  • Classifies each question and loads only the layers it needs, so a quick check-in costs ~200 tokens and a deep recall up to ~1,500, never the whole store
  • Scores importance and rejects low-value and duplicate entries before they're saved; warns when new information contradicts what's already stored
  • Semantic search finds memories even when the question is worded differently
  • Cleans itself up automatically: removes stale entries, promotes important ones, and compacts old episodes
  • Every retrieval reports tokens spent learning something versus tokens spent recalling it
  • One-command setup with npx memorykit-mcp-server init, or install as a Claude Code plugin with /recall and /save commands

Current Status: v2.0.0 on npm with ~73 weekly downloads. In one of my own sessions, a query that would have cost ~74k tokens to rediscover took ~4k with MemoryKit. The repo also includes a .NET API and client SDK.
